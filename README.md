# retro-game-db

Wii 世代（2000年代中盤）までのレトロゲーム情報を収集するデータベース。
まずは**日本国内で発売されたタイトルの一覧**を機種ごとに作成する。

## 収録状況

| 機種 | ファイル | 件数 | 出典 |
|---|---|---|---|
| ゲームボーイアドバンス (GBA) | [`data/gba/jp_titles.csv`](data/gba/jp_titles.csv) | 761 | ja.wikipedia「[ゲームボーイアドバンスのゲームタイトル一覧](https://ja.wikipedia.org/wiki/ゲームボーイアドバンスのゲームタイトル一覧)」 oldid=110862677 (2026-09-01) |

### GBA の既知の欠落

出典ページの本文では「国内発売 全791タイトル」とされているが、ページ内の表には 761 行しかない。
年別件数の比較（本文記載 / 表から抽出）:

| 年 | 本文 | 抽出 | 差 |
|---|---|---|---|
| 2001 | 132 | 132 | 0 |
| 2002 | 209 | 210 | +1 |
| 2003 | 155 | 155 | 0 |
| 2004 | 185 | 158 | −27 |
| 2005 | 79 | 80 | +1 |
| 2006 | 31 | 26 | −5 |

2004年・2006年を中心に約30タイトルが不足している。任天堂公式の発売タイトル一覧
（`nintendo.co.jp/n08/`）などとの突き合わせで補完する予定。廉価版（追加要素なし）は出典の方針により含まない。

## CSV の列

| 列 | 内容 |
|---|---|
| `id` | `<機種>-jp-<連番>`（発売順、出典表の並び順） |
| `release_date` | 国内発売日 `YYYY-MM-DD` |
| `title` | タイトル |
| `publisher` | 発売元 |
| `notes` | 備考（出典の備考欄、脚注は除去） |
| `wikipedia_article` | リンク先の Wikipedia 記事名（シリーズ記事などの場合あり） |

※ `id` は再生成時に出典の行が増減すると変わるため、現時点では安定IDではない。

## 再生成

```sh
python3 scripts/fetch_wikipedia_list.py gba
```
